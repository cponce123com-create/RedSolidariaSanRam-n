Quiero que desarrolles la website de Red Solidaria San Ramón por fases, con una arquitectura escalable, diseño moderno, panel de administración y buena experiencia de usuario.

La organización nació a partir de campañas navideñas para llevar chocolatada y juguetes a niños de escasos recursos en anexos lejanos de San Ramón, Chanchamayo, y ahora busca crecer hacia una plataforma más amplia de ayuda social, campañas solidarias, adopción responsable, ayuda animal, reportes ciudadanos y transparencia de donaciones.

La web debe verse profesional, humana, moderna, confiable y funcional.

OBJETIVO GENERAL

Crear una plataforma web que permita:

Mostrar la identidad de la organización.
Publicar campañas solidarias.
Recibir donaciones económicas y en especie.
Mostrar rendición de cuentas por campaña.
Publicar casos urgentes.
Permitir reportes ciudadanos.
Publicar mascotas en adopción responsable.
Gestionar campañas de ayuda animal.
Captar voluntarios.
Tener un panel administrativo completo.
STACK SUGERIDO

Desarrolla con una arquitectura moderna y ordenada:

Frontend: Next.js o React
UI: Tailwind CSS
Backend: Node.js / API routes / Express si es necesario
Base de datos: PostgreSQL o Supabase
Storage: Supabase Storage o equivalente
Auth: autenticación para admin
Deployment: compatible con Replit

Si propones otro stack, debe mantenerse:

fácil de mantener
